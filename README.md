
# Price-comparision-ai
# 🤖 ШІ-пошук найнижчої ціни

Універсальний пошук цін на товари з автоматичним знаходженням сайтів та ШІ-аналізом.

## 🚀 Як це працює

1. **Пошук сайтів** - через Google знаходить сайти з вашим товаром
2. **Видобування цін** - автоматично знаходить ціни на кожному сайті
3. **ШІ-аналіз** - порівнює ціни та дає рекомендації

# Встановити залежності
